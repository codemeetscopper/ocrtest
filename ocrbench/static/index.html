ISOLATED EXECUTION

Engine environments.

Use a dedicated Python interpreter for each engine to avoid dependency conflicts.

Run python install.py to install all OCR engines and their runtimes. For Python dependencies only, use python -m pip install -r requirements.txt. Every run performs a real-image preflight; package detection alone does not verify compatibility.

Interpreter paths are saved in this browser. GPU runs require a matching CUDA runtime; CPU fallback is rejected. Unsupported telemetry remains unavailable.
