Package source

Configure Artifactory once, then let pip handle package installation.

Personal PC: leave both blank to use PyPI, with official vendor indexes for CUDA builds. Work PC: provide the Artifactory URL and token to save them to user pip.ini. An existing pip source is preserved and used without public fallback.
The token will be stored in plain text in your user pip.ini when you install. It is kept out of installer logs and command arguments. Leave blank if your repository accepts the token as its username. Saved in pip.ini if supplied. Normal certificate verification remains enabled.
